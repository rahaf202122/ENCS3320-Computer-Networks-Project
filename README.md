# ENCS3320 – Computer Networks Project 2

## Project Overview

This repository contains **Project 2 – Network Design** for the **ENCS3320 – Computer Networks** course.

The project was implemented using **Cisco Packet Tracer** and focuses on designing and configuring a small computer network, including IP addressing, subnetting, device configuration, static routing, and network services.

## Project Objectives

The project covers:

* Network design and topology implementation
* IP addressing and subnetting
* Router and switch configuration
* Static IP addressing
* DHCP configuration
* DNS configuration
* HTTP Web Server configuration
* Email Server configuration
* Static routing between multiple routers
* Network connectivity testing and troubleshooting

## Network Topology

The network includes:

* 3 Routers
* 2 Switches
* 3 Servers
* 4 PCs/Laptops

The required topology was implemented and configured in Cisco Packet Tracer.

## Main Tasks

### 1. IP Addressing and Subnetting

A suitable subnetting scheme was designed based on the given network address and the required number of IP addresses for each network.

IP addresses, subnet masks, and default gateways were assigned to the network devices.

### 2. Device Configuration

The network devices were configured according to the project requirements, including:

* Router interfaces
* Switches
* PCs and laptops
* DHCP Server
* DNS Server
* HTTP Web Server
* Email Server

### 3. Static Routing

Static routes were configured between the routers to provide communication between the different networks.

### 4. Testing and Verification

The network was tested to verify:

* Ping connectivity between networks
* DHCP address assignment
* DNS name resolution
* Web server access
* Email communication
* Network paths using `tracert`
* Communication between end devices and servers
